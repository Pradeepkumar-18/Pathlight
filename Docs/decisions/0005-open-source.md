# 0005 · Open source
Date: 2026-11-01 · Status: Accepted

## Context
Licensing was open (open source / freemium / paid).

## Decision
Pathlight Tracker is open source under the **MIT** licence (chosen 2026-11-01: simplest and most familiar; Apache-2.0 was the alternative, for its patent grant).

## Consequences
Add an MIT `LICENSE` file at task 0.2. Developers can read the agent they preload into their app, which builds trust.
